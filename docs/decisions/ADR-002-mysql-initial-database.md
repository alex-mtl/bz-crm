# ADR-002: MySQL 8 как стартовая БД с сохранением переносимости на PostgreSQL

- **Статус:** принято
- **Дата:** 2026-09-30
- **Источник:** ТЗ §4–6, §79–81

## Решение

- MySQL 8.4 (LTS-ветка 8.x) для разработки, тестов, staging и production.
- Автотесты работают на отдельной MySQL-базе `bz_crm_testing`, а не на SQLite: так тесты проверяют ту же СУБД, что и production (ТЗ §4).
- Кодировка `utf8mb4`, collation `utf8mb4_unicode_ci` (ro/ru/en-контент).
- Только Eloquent/query builder и миграции Laravel. Сырой SQL — только по правилам ТЗ §4: обоснование, изоляция в отдельном query/repository-классе, документация.
- Без нативных `ENUM` для бизнес-состояний: PHP Enum + строковый код в БД + справочник (ТЗ §5).
- Пространственные операции — только через `GeoService` (ТЗ §6, §32).

## Последствия

- Будущая миграция на PostgreSQL/PostGIS (ТЗ §80) не должна требовать переписывания доменной логики.
- Любое отступление от этих правил требует нового ADR.
