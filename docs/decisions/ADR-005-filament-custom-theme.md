# ADR-005: Собственная тема Filament, собираемая через Vite

- **Статус:** принято
- **Дата:** 2026-09-30
- **Источник:** ТЗ §7, §8

## Контекст

Filament поставляет заранее скомпилированный CSS, в который попадают только классы из его собственных шаблонов. Tailwind-классы в наших страницах и компонентах (`flex`, `justify-between`, `divide-y` и т.д.) без собственной темы не применяются — это проверено в браузере на странице «Состояние системы».

## Решение

- Тема `resources/css/filament/admin/theme.css` импортирует базовую тему Filament и сканирует `app/Filament/**` и `resources/views/filament/**`.
- Подключена в `AdminPanelProvider` через `->viteTheme(...)` и в `vite.config.js` как отдельный input.
- Генератор `make:filament-theme` не используется: он требует Node в PHP-контейнере; файл создан по шаблону из `vendor/filament/filament/stubs/ThemeCss.stub`.

## Последствия

- Любое изменение классов в шаблонах панели требует запущенного `node` (dev) или `npm run build`.
- Тесты не зависят от собранных ассетов: `TestCase` вызывает `withoutVite()`.
- При добавлении новых панелей Filament (например, пользовательской) — отдельная тема на панель.
