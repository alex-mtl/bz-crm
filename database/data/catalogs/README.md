# Стартовые справочники

Справочные данные (не демо): загружаются во всех окружениях, включая `production`, идемпотентно по полю `code`. Решение — [Д-16](../../../docs/requirements-addendum.md).

## `task-types.csv` — типы задач (вопрос №10)

| Поле | Смысл |
|---|---|
| `code` | неизменяемый код в БД (ТЗ §48) |
| `name_ro`, `name_ru`, `name_en` | названия на трёх языках |
| `requires_review` | `1` — задача этого типа закрывается только через `in_review` (ФО §6.8.4); `0` — можно сразу из `in_progress` в `done` |
| `is_system` | `1` — элемент нельзя деактивировать: на него опирается логика (например, «Прочее» — значение по умолчанию) |
| `phase` | фаза, в которой тип становится полезен. Все типы загружаются сразу, но типы будущих фаз скрыты, пока их модуль не реализован |
| `description_ru` | назначение и ссылка на ФО |

Правило «проверка обязательна / не обязательна» по типу задачи взято из ФО §6.8.4. Сама сущность «тип задачи» в модели ФО §7 отсутствовала — её добавляет это решение.

**Переводы.** Названия ro/en — наши рабочие формулировки: у типов задач, в отличие от территорий, нет официального источника. Перед запуском их должен вычитать носитель румынского языка (Д-8).
