# Справочник территорий Молдовы — исходные данные

Реальные справочные данные (география), а не демо-данные: загружаются во всех окружениях, включая `production`. Решения — [Д-6…Д-9](../../../docs/requirements-addendum.md).

## Иерархия (Д-7)

```
Республика Молдова
└── макрорегион (6)          md-macro-regions.csv      — по Закону 438/2006 о региональном развитии
    └── район / муниципий (37)  md-adm1-units.csv         — + контуры md-adm1-boundaries.geojson
        └── населённый пункт / сектор (1684)  md-localities-official.csv — по Закону 764/2001
```

Уровни — настраиваемый справочник: глубину можно добавлять (избирательные участки, дома), содержимое править.

## Как собраны названия

1. **Мастер-список — Закон 764/2001 «Об административно-территориальном устройстве»**, приложения 2–5, в редакции на legis.md (последнее изменение закона — 28.06.2025; русские приложения 2 и 3 — редакции v5 и v6). Это официальная номенклатура: румынские названия и официальные русские названия из русской версии закона.
2. Румынский и русский тексты разобраны и сопоставлены по районам: выравнивание последовательностей по сходству транслитерации, затем второй проход для записей, перечисленных в разном порядке. Итог — 1684 пары, у 17 пар с низким сходством все проверены вручную: это железнодорожные посёлки с пометкой «loc.st.cf / н.п.ж.-д.ст.». Пометка вынесена в поле `railway_station`.
3. Румынская орфография приведена к современной: ş → ș, ţ → ț. Буква «î» сохранена, как в официальных молдавских названиях (Rîșcani, Sîngerei, Hîncești).
4. **Английские названия** — официальные румынские с диакритикой, как в англоязычных источниках (Chișinău, Bălți). Исключения: ATU Gagauzia, Left Bank of the Dniester, Bender.
5. **Координаты** — из GeoNames по совпадению нормализованного названия внутри района: есть у 1605 из 1684 записей (95%). Для остальных 79 координаты нужно добавить позже.
6. **Ручные исправления дефектов источника** перечислены в `md-localities-review.txt`: перестановка при выравнивании в Теленештском районе; отсутствующий в русском приложении «Borceag» (Тараклия); опечатки русского docx («Рышкова Рышкова», «Сэрата-Резэшь», дубль «Сергеука»).

## Официальные названия и синонимы для поиска (Д-9)

Показываются только официальные названия. У 24 из 37 единиц официальная русская форма закона отличается от привычной: «Кишинэу» / «Кишинёв», «Бэлць» / «Бельцы», «Орхей» / «Оргеев», «Унгень» / «Унгены». Привычные формы хранятся в `search_aliases` и нужны только поиску, чтобы территория находилась по любому варианту. Для справки: Google Maps сам непоследователен — «Кишинёв», «Бельцы», «Сороки», но «Орхей», «Унгень», а сёла в официальной форме.

## Известные пробелы

1. У 79 официальных населённых пунктов нет координат (список — в `md-localities-review.txt`).
2. 188 записей GeoNames не входят в официальный перечень: хутора, станции, дубли, названия в английской транслитерации с русского («Brichany», «Muzhik»). В справочник они не попадают.
3. Нет контуров секторов Кишинёва и населённых пунктов — только точки.
4. Нет избирательных участков — нужен отдельный источник (ЦИК).
5. Закон перечисляет пункты плоско по району; принадлежность села к коммуне (примэрии) в итоговый файл пока не вынесена, хотя в источнике она есть. Если понадобится уровень «коммуна» — её можно достать из тех же приложений.
