# Файлы демо-мира

Только вымышленные данные (Д-2). Используются демо-сидером и для показа импорта вживую; в `production` не загружаются.

| Файл | Зачем |
|---|---|
| `people-import-sample.csv` | Файл с ошибками и дублями — показывает отчёт импорта: строка без имени, неверный email, неизвестная территория, неизвестный тип, дубль внутри файла, дубль с карточкой из реестра (Doina Vrabie). Импорт такого файла отклоняется целиком. |
| `people-import-clean.csv` | Чистый файл: три сторонника в Cahul — импортируется полностью. |
